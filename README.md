# 🩺  AGENTIC AI Appointment & Symptom Analysis System

An interactive, web-based "Virtual Clinic" application designed to simulate a doctor-patient consultation flow. The system features an automated first-come, first-served appointment queuing system, dynamic AI-driven symptom analysis, and adaptive health/treatment guidance using LLM capabilities (Claude API).

---

## ✨ Features

- **📋 First-Come, First-Served Queue System**
  - Instant ticket generation upon check-in with real-time waiting room updates tracking queue position.
- **💬 Agentic AI Medical Assistant**
  - Dynamic, conversational consultation that adapts follow-up questions based on specific patient complaints (e.g., respiratory, digestive, headaches, skin, or injury).
- **🚨 Safety First & Emergency Triage**
  - Multi-layered safety checks combining AI evaluation and client-side keyword detection for red-flag symptoms (e.g., severe chest pain, breathing difficulty, stroke signs).
  - Immediate redirect to emergency services when critical symptoms are flagged.
- **📄 Comprehensive Visit Summaries**
  - Formats consultation findings into an organized "Health Note" containing condition-specific self-care measures, hydration/rest protocols, and OTC comfort recommendations.
- **⚖️ Built-in Responsible AI Boundaries**
  - Designed strictly as a triage and educational assistant. Provides non-diagnostic self-care suggestions and avoids direct prescription of regulated medications/dosages.
